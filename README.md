# Data Analytics Learning

A hands-on learning journey focused on data analytics, business intelligence, and applied statistics.

This repository documents my progress as I build practical skills in SQL, Excel, Power BI, Python, and statistical analysis.

## Goals

- Develop practical SQL skills for querying and analyzing data.
- Learn to clean, transform, and interpret real-world datasets.
- Build reports and dashboards using Power BI.
- Apply Python to data analysis and visualization.
- Refresh and apply mathematical and statistical concepts.
- Develop a portfolio demonstrating analytical thinking and technical skills.

## Background

I bring over 10 years of software development experience, primarily in frontend engineering, along with an academic background in mathematics.

This project builds on that foundation while developing a stronger focus on working with data, identifying patterns, answering questions, and communicating findings.

## Repository Structure

- `learning-log/` — Learning progress, notes, and resources.
- `sql/` — SQL exercises and projects.
- `excel/` — Spreadsheet analysis.
- `power-bi/` — Data models, reports, and dashboards.
- `python/` — Python-based data analysis.
- `projects/` — End-to-end analytical investigations.

## Learning Philosophy

The emphasis is on practical application rather than simply completing tutorials.

Projects will focus on specific questions, documenting the analytical approach, explaining decisions, and communicating findings.
